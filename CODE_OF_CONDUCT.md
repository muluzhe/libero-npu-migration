# Code of Conduct

We follow the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be patient and kind, assume good intent, give constructive feedback, and focus on what is best for the community. Disrespectful behavior will not be tolerated.

To report an issue, contact the maintainers via a private GitHub security advisory or open an issue tagged `conduct`.
